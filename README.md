# Sales Analytics | Telecom Dashboard & Customer Analysis

A data analytics portfolio project featuring a Power BI dashboard, an Excel-based RFM analysis workbook, a dashboard report, and a telecom dataset, with a dedicated folder for predictive analytics.

## 📌 Project Overview

The **Sales Analytics** project is a data analytics initiative focused on exploring telecom-related data through business intelligence reporting and customer analysis.

The repository brings together dashboard reporting, spreadsheet-based analysis, and resources for predictive analytics. It is intended to demonstrate practical work with data analysis and business reporting tools.

## 🎯 Project Objectives

* Organize telecom data for analytical exploration.
* Present data through an interactive Power BI dashboard.
* Explore customer analysis using an RFM analysis workbook.
* Provide a PDF version of the dashboard report.
* Maintain a dedicated space for predictive analytics work.

## 📊 Project Components

### 1. Power BI Dashboard

**File:** `Telecom_Dashboard.pbix`

The Power BI file is the primary dashboard artifact in this repository. It can be opened in Microsoft Power BI Desktop to inspect the report pages, visualizations, and underlying data model.

The dashboard's individual KPIs, chart definitions, and business findings should be documented after reviewing the report itself.

### 2. RFM Analysis

**File:** `Telecom_RFM_Analysis.xlsx`

The Excel workbook is dedicated to RFM analysis.

RFM stands for:

* **Recency:** How recently a customer interacted or transacted.
* **Frequency:** How often a customer interacted or transacted.
* **Monetary:** The monetary value associated with a customer's transactions.

RFM analysis is commonly used to understand customer behavior and support customer segmentation. The exact scoring method, customer segments, and findings in this workbook have not been independently verified.

### 3. Dashboard Report

**File:** `Telecom_dashboard.pdf`

The PDF file provides a report version of the dashboard. It can be used to review and share the dashboard output without requiring the recipient to open the Power BI project file.

### 4. Telecom Dataset

**File:** `telecom_dataset.zip`

The repository includes a compressed dataset for the project. The dataset's exact schema, record count, field definitions, source, and data quality have not yet been verified.

### 5. Predictive Analytics

**Folder:** `Predictive analytics/`

This folder is reserved for predictive analytics resources. The specific algorithms, training procedures, evaluation metrics, and model results should be documented after inspecting its contents.

## 🚀 Getting Started

### Prerequisites

* A computer running Windows or another supported environment for the selected tools.
* Microsoft Power BI Desktop to open the `.pbix` dashboard.
* Microsoft Excel or a compatible spreadsheet application to open the `.xlsx` workbook.
* A PDF reader to view the dashboard report.

### Installation and Usage

**Step 1: Clone the repository**

```bash
git clone https://github.com/DhanaVazanth/Sales-Analytics.git
```

**Step 2: Navigate to the project directory**

```bash
cd Sales-Analytics
```

**Step 3: Explore the dashboard**

Open `Telecom_Dashboard.pbix` in Power BI Desktop.

**Step 4: Review the RFM workbook**

Open `Telecom_RFM_Analysis.xlsx` in Microsoft Excel.

**Step 5: View the dashboard report**

Open `Telecom_dashboard.pdf` using a PDF reader.

**Step 6: Access the dataset**

Extract `telecom_dataset.zip` and inspect the available data files before attempting to reproduce the analysis.
